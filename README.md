## 🚨 The Problem & Context
New-age interdisciplinary engineering programs like **Computer Science & Business Systems (CSBS)** frequently lack established historical career pathways, structured mentorship ecosystems, and centralized guidance models. Junior students often struggle to balance academic CGPA requirements, specialized skill development, internship targets, and strategic placement preparations. This friction stems from scattered legacy advice and the lack of a system that preserves senior-driven insights. 

## 🛡️ Our Solution: Current Crew's Decision Support Platform
Developed under the banner of **Team Current Crew** led by **Renuka R**, our project preserves institutional knowledge and acts as an intelligent decision-support system specifically for interdisciplinary curricula. 

By evaluating unique student profiles, real-world senior experiences, course structures, and corporate recruitment trends, it transitions students from guesswork to data-driven strategic planning.

---

## 🌟 Key Features

* 📊 **Student Profile Analysis:** Dynamically tracks critical metrics including current CGPA, semester milestones, structural interests, internship statuses, and career trajectories.
* 🧠 **Personalized Career Guidance:** Generates highly granular, logically reasoned career path tracking optimized for custom profiles.
* 🎓 **Senior Experience Integration:** Directly utilizes insight layers harvested from past CSBS graduates to deliver realistic, ground-truth pathfinding advice.
* 🙈 **Anonymous Mistake Insights:** Systematically logs and highlights institutional failure points across placements, grading milestones, and major development plans.
* 🧪 **What-If Decision Simulator:** Empowers students to model and simulate the complex outcomes of electives, certification types, and technical project structures.
* 📉 **Progress & Gap Analysis:** Automatically cross-references dynamic student profiles against localized recruitment matrices to output gap audits.
* 📚 **Syllabus-Grounded AI Assistant:** Features an intelligent academic workspace backed by exact structural curriculum criteria to guarantee hallucination-free support.
* 🗣️ **Mentor-Style Chat Interface:** Provides conversational context windows built directly on senior student histories to deliver professional guidance.

## 🛠️ System Architecture & Tech Stack

Our solution is built with a highly secure, modern decoupled cloud infrastructure engineered to scale seamlessly:

### Applied Technologies
* **Reasoning Engine:** **Google Gemini API** (Deployed for core contextual reasoning, structural guidance processing, and context-grounded evaluation rather than standard keyword matching).
* **Frontend UI Architecture:** React.js, TypeScript, Vite, Tailwind CSS, shadcn/ui, React Query, React Hook Form, Zod.
* **Backend Cloud Infrastructure:** Supabase Platforms (Authentication Services, secure Row-Level Security policies, and centralized API gateways).
* **Database Management Layer:** Highly scalable PostgreSQL Database configurations.
